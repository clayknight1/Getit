# Shopping List App (Next.js)

A multi-tenant shopping list web application built with Next.js, React, and TypeScript.

## Tech Stack

- **Frontend:** Next.js 16, React 19, TypeScript
- **Styling:** Radix UI
- **Backend:** Next.js API Routes (Server Components + Client Components)
- **Database:** PostgreSQL with Drizzle ORM
- **Authentication:** Better-Auth
- **Animations:** Motion (Framer Motion)

## Features

- Multi-tenant architecture with tenant isolation
- User authentication and authorization
- Create, edit, and delete shopping lists
- Server-side rendering for performance
- Responsive design for mobile and desktop

## Status

**Work in Progress** - Personal learning project exploring Next.js, multi-tenant patterns, and full-stack TypeScript development.

## Running Locally

git clone https://github.com/clayknight1/your-repo-name.git

# Set up environment variables
cp .env.example .env.local

# Run development server
npm run dev
